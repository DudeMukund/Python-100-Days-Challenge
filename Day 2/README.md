# Day 2: Data Types, Operators & F-Strings

## What I Learned Today

### Data Types
Learned about Python's core data types:
- **`int`** — whole numbers (e.g., 5, 100)
- **`float`** — decimal numbers (e.g., 3.14, 20.5)
- **`str`** — text/strings (e.g., "Hello")
- **`bool`** — True/False values

### Operators
Explored different types of operators in Python:
- **Arithmetic operators** (`+`, `-`, `*`, `/`, `**`, `%`) — for 
  performing calculations
- **Comparison operators** (`==`, `!=`, `>`, `<`) — for comparing 
  values
- Understood operator precedence — how Python decides which 
  operation to perform first in an expression

### F-Strings
Learned how to use **f-strings** for cleaner, more readable string 
formatting:
```python
name = "Dude"
print(f"Hello, {name}!")
```
Instead of manually concatenating strings with `+`, f-strings let 
you directly embed variables inside `{}` — much cleaner and easier 
to read.

Understanding data types and operators is fundamental — every 
calculation or logic in a program depends on knowing what type of 
data you're working with. F-strings made formatting output so much 
cleaner compared to manual string concatenation.
