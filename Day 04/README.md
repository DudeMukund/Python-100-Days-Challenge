# Day 4: Lists, Randomization & Mini Projects

## What I Learned Today

### Lists (Basics)
- Lists are **mutable** in Python — meaning elements can be changed 
  after creation
- Learned how to:
  - Add elements (`append()`, `insert()`)
  - Remove elements (`remove()`)
  - Replace/change existing elements
  - Slice lists to get specific portions
- Explored **nested lists** — lists inside other lists

### Randomization
- Learned how to import and use the `random` module
- A **module** is a piece of pre-written code (like a small toolbox) 
  that can be imported and reused across different programs, instead 
  of writing the same logic from scratch
- Used the `random` module to generate random values for project logic

## Mini Projects

### 1. Heads or Tails
A simple coin flip simulator using the `random` module to randomly 
pick between "Heads" and "Tails."

### 2. Rock, Paper, Scissors
Built a fully functional Rock, Paper, Scissors game where the user 
picks an option, the computer randomly generates its choice, and the 
program determines the winner based on the game's rules.

This was genuinely one of the most fun projects so far — really 
solidified my understanding of conditionals combined with 
randomization.

## Key Takeaway
Understanding how modules work (like `random`) opened up a lot of 
possibilities — realized that Python has a huge ecosystem of 
pre-built tools that can be reused instead of reinventing the wheel.
