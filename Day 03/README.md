# Day 3: Conditionals (if, elif, else)

## What I Learned Today

### If, Else, and Elif Statements
Learned how to control the flow of a program based on conditions.

**Basic structure:**
```python
if <condition is true>:
    <execute this line>
else:
    <execute this instead>
```

**Key concepts:**
- **`if`** — runs a block of code only when a condition is `True`
- **`else`** — runs when the `if` condition is `False`
- **`elif`** — used to check multiple conditions in sequence, in case 
  the first `if` condition fails but another one might be true

**Important rule I learned:** When the `if` condition fails, the 
`else` block automatically executes — this is how Python decides 
which path to take based on the situation.
